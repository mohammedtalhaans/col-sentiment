# DARK — DS_05 research dashboard

Compiled static release of the Australian social media sentiment and misinformation analysis project.

Live site: https://mohammedtalhaans.github.io/col-sentiment/

Released 2 October 2026. Four pages: Home, Sentiment, Misinformation, About.
The source-aware rule queue contains 1,357 candidates from 19,787 posts; candidates are not confirmed misinformation.
High, medium and low priority examples are now available. RoBERTa was adapted locally and full author text was re-scored; VADER label cutoffs were calibrated on development data. The rules guide review and do not automatically confirm misinformation. Six selected examples have worked evidence checks; one of those six has a misleading calculation finding. The total amount of misinformation in the dataset is unknown. AI-assisted worked checks await team sign-off. Website text contains no em dashes.
About provides actual models, provisional validation results and the models and methods guide.

This repository contains compiled assets and limited public-post excerpts. The corpus database and original annotation submissions are not published here.
